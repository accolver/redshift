## Certified claim

Redshift v0.14.0 provides bounded owner-authenticated secret history observation, metadata-only key comparison, and explicit full-bundle or tombstone restore in the CLI and browser. A restore publishes a new owner-authorized NIP-59 state; it does not rewrite or delete prior relay events.

The implementation preserves deterministic logical ordering by inner rumor timestamp and lowest outer event ID, owner/recipient/seal/rumor authorization, exact d-tags, fixed pre-decryption resource bounds, quorum publication, degraded-outcome visibility, and exact-event publication recovery.

History remains only the bounded state observed from responding configured relays. This release does **not** claim complete or durable history, retention, audit/compliance logging, cryptographic erasure, Nostr compare-and-swap, managed backups, geographic redundancy, RPO/RTO, availability, or SLA guarantees.
