## Certified scope

Redshift v0.14.2 certifies the sovereign individual CLI and dashboard on Linux
and macOS, x64 and arm64. It includes the security and product-truth hardening
merged through [PR #50](https://github.com/accolver/redshift/pull/50), the
isolated relay-preflight dependency correction in
[PR #51](https://github.com/accolver/redshift/pull/51), and authenticated GitHub
API requests for forced updater verification in
[PR #53](https://github.com/accolver/redshift/pull/53).

This evidence does **not** certify a Redshift-operated managed relay, paid Cloud,
Teams, Enterprise SSO, managed retention or backup, an availability objective,
RPO/RTO, or an SLA. Those capabilities remain deferred behind separately
approved OpenSpec and operational evidence.

independent verification workflows, so emulated macOS-host Docker is not used as
platform certification.

## v0.14.1 incident and fix-forward

The `v0.14.1` workflow
[29229751056](https://github.com/accolver/redshift/actions/runs/29229751056)
built, attested, published, and installed all assets, but both macOS journeys
then hit anonymous GitHub REST API rate limits during forced updater replacement.
The recovery job marked `v0.14.1` prerelease and non-latest. Its original tag,
assets, and digests remain preserved; no asset was replaced or clobbered.

Redshift fixed forward on v0.14.2. The updater now attaches `GH_TOKEN` or
`GITHUB_TOKEN` only to requests whose API base is exactly
`https://api.github.com`; it does not forward credentials to test override
origins or release download URLs. Provenance, checksum, candidate smoke testing,
and atomic replacement remain mandatory.

## Web deployment and managed-relay boundary

Cloudflare Pages reported a successful production deployment for the release
commit. Production inspection found no Cloudflare Insights beacon and no
operative drop-in-compatibility claim. The public installer requires GitHub
attestation and exact checksum verification before installation.

The managed-relay source passed its credential-free preflight, but protected
production deployment remained intentionally skipped because the
`operationalize-managed-production` proposal is unapproved and repository
approval/credentials are absent. Reachability or historical relay metadata is
not treated as certification. Payment and commercial onboarding remain disabled
in current source, and the live relay must not be represented as matching that
source until an approved exact-commit deployment and post-deploy verification
complete.

## Evidence-bounded conclusion

`v0.14.2` is the certified production release for Redshift's individual product
on the four named native targets. The evidence supports release integrity and
those tested individual workflows only. It does not support managed-service,
retention-duration, uptime, RPO/RTO, or SLA claims.
